# 📌 Overview

The IRCTC Reservation System is a console-based Java application designed to simulate real-world railway reservation workflows.

This project demonstrates:

- Object-Oriented Programming (OOP)
- Modular Service Architecture
- Java Collections Framework
- Console UI Design using ANSI Colors
- In-Memory Database Management
- Ticket Booking Workflow
- PNR Generation & Tracking

---

# ✨ Features

## 🚆 Train Management
- Search trains using source & destination
- View all trains
- View available stations
- Search by train number
- Train details display

## 🎫 Booking System
- Ticket booking workflow
- Seat availability validation
- Dynamic fare calculation
- Passenger information management

## 📄 PNR & Ticket System
- Auto-generated unique PNR number
- Printable ticket layout
- Booking timestamp generation
- Booking status tracking

## ❌ Cancellation System
- Ticket cancellation
- Seat restoration after cancellation
- Refund simulation

## 🎨 Premium Console UI
- ANSI color terminal interface
- Dashboard-style menus
- Aesthetic ticket printing
- Professional landing banner

# 🚀 Getting Started

## 📥 Clone Repository

```bash
git clone https://github.com/bani80225-prog/Irctc-Reservation-System.git
```

## ▶️ Compile Project

```bash
javac src/*.java -d out
```

## ▶️ Run Application

```bash
java -cp out project_1.IRCTCMain
```
